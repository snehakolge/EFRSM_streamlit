# 🏦 Enterprise Fraud Risk Monitoring System (EFRMS)

AI-Powered Fraud Detection • RBI Early Warning Signals • Real-Time Fraud Surveillance

---

# 📌 Overview

This project simulates an enterprise-grade Fraud Risk Monitoring System used by banks and financial institutions for:

- Real-time fraud detection
- RBI Early Warning Signals (EWS)
- Transaction surveillance
- Fraud analytics
- Alert monitoring
- Investigator case management
- SHAP explainability
- Anomaly detection

The system combines:

- XGBoost Machine Learning
- Isolation Forest Anomaly Detection
- RBI-inspired EWS rules
- SHAP Explainability
- Real-time monitoring dashboard

---

# 🚀 Features

## ✅ Real-Time Fraud Detection

- Fraud probability scoring
- Risk classification
- Alert generation
- Fraud threshold engine

---

## 🏦 RBI Early Warning Signals (EWS)

The system includes simulated RBI EWS scenarios such as:

- Rapid movement of funds
- High transaction velocity
- Shared device risk
- Structuring / smurfing risk
- Merchant network anomalies
- Account takeover indicators
- Suspicious night transactions
- Abnormal customer behavior

# ▶️ Run Locally

## Install dependencies

```bash
pip install -r requirements.txt
```

## Start application

```bash
streamlit run app.py
```

# 📈 Model Performance

Current model performance:

- Fraud Recall: ~82%
- Fraud Precision: ~99%
- Fraud F1 Score: ~90%

The model was intentionally designed with realistic noisy fraud patterns to avoid overfitting and simulate enterprise fraud behavior.
