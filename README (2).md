# 🏦 Enterprise Fraud Risk Monitoring System (EFRMS)

## 📌 Project Overview

The Enterprise Fraud Risk Monitoring System (EFRMS) is an AI-powered real-time fraud surveillance and risk monitoring platform designed for banking and financial services environments.

The system combines:

- Machine Learning-based fraud prediction
- RBI-aligned Early Warning Signal (EWS) rules
- Hybrid fraud risk scoring
- Real-time fraud alert generation
- Investigator case management dashboard

The solution is designed as a prototype inspired by enterprise fraud monitoring systems used in banks and financial institutions.

# 📊 Fraud Monitoring Parameters

The system monitors multiple fraud indicators including:

- Transaction Velocity
- Night Transactions
- Shared Device Activity
- Abnormal Transaction Amounts
- Rapid Sequential Transactions
- Customer-Merchant Transaction Frequency
- Behavioral Risk Patterns

---

# 🏦 RBI-Aligned Early Warning Signals (EWS)

The system includes rule-based Early Warning Signals inspired by fraud monitoring practices used in banking environments.

Examples include:

- High transaction velocity
- Rapid back-to-back transactions
- Shared device fraud patterns
- Unusual transaction deviations
- Night-time suspicious activity
- Repeated merchant interactions

# 📂 Dashboard Modules
